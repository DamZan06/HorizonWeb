## ABSOLUTE PRIORITY — FIX DUPLICATED INITIALIZATION

The website currently loads:

* js/config.js
* js/i18n.js
* js/status.js
* js/app.js
* script.js

The old `script.js` still contains thousands of lines of legacy logic that overlap with the newer modular scripts.

There is currently a serious initialization problem.

`app.js` creates an 8-second interval for home data refresh.

But the legacy `script.js` also contains an interval that calls:

`app.init()`

every 8 seconds.

Because `app.init()` itself creates another interval, new timers can accumulate while the page remains open.

FIX THIS IMMEDIATELY.

`app.init()` must execute exactly ONCE per page load.

Never repeatedly initialize:

* navigation event listeners
* language controls
* timers
* Firebase listeners
* DOM observers

Create persistent refresh intervals only once.

Use explicit guards if useful, for example:

`app.initialized`

or equivalent.

There should ideally be only ONE home live-data refresh scheduler.
